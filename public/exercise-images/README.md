# Exercise example images

Drop a `.webp` image here named after the exercise, slugified: lowercase,
punctuation stripped, spaces/dashes collapsed to single hyphens. The
workout screen matches these automatically — no code change needed.

Examples:
- "Dumbbell Shoulder Press" → `dumbbell-shoulder-press.webp`
- "Dumbbell Bent Over Row (neutral grip)" → `dumbbell-bent-over-row-neutral-grip.webp`

If there's no local image for an exercise, the card falls back to a Vimeo
thumbnail (when the exercise has a `player.vimeo.com` video link) and then
to a generic placeholder icon.
